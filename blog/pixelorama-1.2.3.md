Hello! Today we have a quick little update for you, version 1.2.3! It's very small, but we had to release it because it contains a very important bug fix, which was introduced in v1.2.2, where Pixelorama would freeze when you used the bucket tool on an active selection. But we managed to sneak it a few little improvements as well!

If you wish to support us, you can [become a Patron](https://www.patreon.com/OramaInteractive) and receive exclusive awards, or [buy Pixelorama on Steam](https://store.steampowered.com/app/2779170/Pixelorama/), [or from itch.io](https://orama-interactive.itch.io/pixelorama)!

## Full changelog of version 1.2.3:

### Added
- Locking guides in place is now possible from the View menu. [#1612](https://github.com/Orama-Interactive/Pixelorama/pull/1612)
- Cloning cels is now possible when you hold Shift while dragging them. [#1590](https://github.com/Orama-Interactive/Pixelorama/pull/1590)
- You can now center the content of cels from the cel button's right click menu, in the timeline. [#1605](https://github.com/Orama-Interactive/Pixelorama/pull/1605)

### Fixed
- Fixed Pixelorama freezing when using the bucket tool when a selection is active.
